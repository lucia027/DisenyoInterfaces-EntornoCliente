# 🎨 DiseñoInterfaces - EntornoCliente

Repositorio destinado a los ejercicios y prácticas iniciales de las asignaturas de **Diseño de Interfaces Web** y **Desarrollo Web en Entorno Cliente** de **2º de DAW**.

## 📚 Contenido

En este repositorio iré subiendo pequeños ejercicios realizados durante las primeras semanas del curso.

El objetivo es mantener organizadas las prácticas sencillas de ambas asignaturas hasta comenzar proyectos más grandes, los cuales tendrán su propio repositorio independiente.

### 🎨 Diseño de Interfaces Web

Ejercicios relacionados con:

* Diseño y estructura de interfaces.
* HTML y CSS.
* Diseño responsive.
* Accesibilidad y usabilidad.
* Maquetación web.
* Buenas prácticas de diseño.

### 💻 Desarrollo Web en Entorno Cliente

Ejercicios relacionados con:

* JavaScript.
* Manipulación del DOM.
* Eventos.
* Funciones y estructuras de datos.
* Interacción con el usuario.
* Desarrollo de aplicaciones web en el lado del cliente.

## 🎯 Objetivo

Este repositorio sirve como recopilación de ejercicios pequeños y prácticas realizadas durante el aprendizaje de ambas asignaturas.

Cuando los proyectos tengan una mayor complejidad o tamaño, se desarrollarán en **repositorios independientes** para mantener una mejor organización.
